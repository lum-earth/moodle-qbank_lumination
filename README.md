# Lumination AI Question Generator for Moodle

Generate multiple-choice questions from a PDF or Word document with AI, straight into your Moodle question bank. Part of the Lumination AI plugins for Moodle.

## How it works

1. In a question bank, open the **Generate with AI** tab.
2. Upload a document (PDF, DOCX or TXT), and choose how many questions, the difficulty and the language.
3. The questions are written in the background through Moodle's cron. A progress page shows when they are ready, usually within a minute.
4. They land in a new category, "Generated by Lumination AI", inside the category you were viewing. Each question has an explanation in its general feedback, the document page it comes from, and a hint for students' next attempt. Review them, then add them to a quiz.

The document is sent to the AI Tutor API and deleted from Moodle after the job.

## Requirements

- Moodle 5.0 or later, with cron running
- The Lumination AI Provider (`aiprovider_lumination`), set up with an AI Tutor API key under **Site administration > AI > AI providers**. It holds the key for all Lumination AI plugins.
- Teachers need permission to add questions and manage question categories in the question bank.
